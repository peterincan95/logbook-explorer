CLIWOC release 2.1
(25 September 2007)
After finishing the official CLIWOC project, there were still some unfinished businesses. E.g. there were some 7,000 records on the shelf that were - due to time restrictions - not included in version 1.5. These records are now included. On the other hand, some records seemed to have been duplicated during the data entry procedure. These have been eliminated in this new version. Several corrections were made to the various zeromerdians, and thus to the ships' positions as well. Further some investigation has been done to the numerous ways of recording the air pressure and the used units. Most of the SLP readings are now - within reason - usable. After releasing version 2.0 some annoying errors appeared in the ASCII versions of this release. Additiononally some small errors emerged. All in all a reason enough to release this latest version 2.1.
